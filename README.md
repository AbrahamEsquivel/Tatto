##Descripción del Proyecto

**B-ink Tattoo Manager** es una solución web integral diseñada para estudios de tatuajes profesionales. El sistema permite la administración eficiente de la agenda de artistas, gestión de clientes, control de citas y seguimiento de historial de trabajos.

El objetivo es digitalizar el flujo de trabajo de un estudio (como B-ink Tattoo), eliminando el uso de papel y centralizando la información en una base de datos segura y normalizada.


##Funcionalidades Principales

* **Gestión de Usuarios:** Login seguro para administradores y artistas con encriptación de contraseñas (`password_hash`).
* **Agenda Inteligente:** Visualización y creación de citas validando disponibilidad de horarios y artistas.
* **Restricciones de Negocio:** Triggers en base de datos para evitar errores lógicos (ej. máximo de detalles por venta).
* **Gestión de Clientes:** Registro detallado de información personal y de contacto.
* **Catálogos Dinámicos:** Gestión de estilos de tatuaje, partes del cuerpo y listas de precios.
